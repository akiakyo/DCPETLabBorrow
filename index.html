            Data management

            Export

            Downloads every request, the audit trail and your preferences as one JSON file. Export before importing or resetting so you can restore what you have now.

            Import

            The file is checked first. Nothing changes until you confirm.

            Reset

            Replaces all requests with the original sample data and starts a new audit trail. Preferences are kept.

            Only the lab head (admin) can export, import or reset data.
